# REP 进销存管理系统（Resource & Enterprise Planning）

面向机械锁厂的轻量级联网 ERP：管理供应商、购买方、产品/零部件库存、订单与财务，支持 Excel 批量导入导出。
**一个网址，电脑浏览器和手机浏览器都能用**，数据可本地离线使用，也可配置云同步实现多端共享。

---

## 一、技术栈
- React 18 + TypeScript + Vite
- Ant Design 5（中文、深色/浅色自适应、响应式）
- Dexie（IndexedDB）：本地离线数据库，无需后端即可跑
- XLSX：Excel 导入导出
- 可插拔同步层：本地优先 + 可选 REST 云同步

## 二、本地运行 / 打包
```bash
npm install
npm run dev        # 本地开发，浏览器打开 http://localhost:5173
npm run build      # 产出 dist/ 静态文件，可部署到任意静态托管
npm run preview    # 预览构建产物
```
构建后把 `dist/` 部署到任意静态网站（Vercel / Netlify / GitHub Pages / 香港对象存储 / 内网穿透）即可通过网址访问，手机同样适用。

## 三、多端同步方案（免 ICP 备案）
系统默认数据仅存本地（每台设备独立）。要手机/电脑共享同一份数据，二选一：

**方案 A：内网穿透（最快）**
1. 启动同步后端：`node server/sync-server.mjs`（默认端口 8787）。
2. 用 cpolar / ngrok 把本地 8787 暴露成 https 公网地址。
3. 在系统「设置 → 云同步」填入该地址和密钥，点「立即同步」。

**方案 B：香港/境外云（最稳）**
把 `server/sync-server.mjs` 上传到 Render / Railway / Fly.io 等免费 Node 平台，
把分配的 https 地址填到「设置 → 云同步」即可。

> 同步逻辑：`sync.ts` 用「拉取远端 → 合并导入 → 推送本地」策略，保证不丢数据。
> 即使不配云同步，也建议每周用「设置 → 数据备份」导出一份 JSON 留底。

## 四、功能对照（按需求逐条实现）
- 左侧固定菜单：供应商 / 购买方 / 库存 / 产品 / 订单 / 金额（及首页仪表盘、回收站、设置）。
- 全局：每个列表支持 Excel 导入导出、全局搜索、分页（10/20/50）、软删除（回收站可恢复）、唯一编号（SUP/BUY/PRO/PAR/ORD + 年月 + 序号）。
- 供应商/购买方：CRUD、导入、点击名称进入其专属订单页（全部/进行中/已完成筛选）。
- 库存：产品库存 / 零部件库存二级菜单；产品可下钻查看其 BOM 零部件库存与「可支撑产量」。
- 产品：含 BOM 物料清单维护（锁芯/锁体/面板/弹簧/螺丝/执手/钥匙…）。
- 订单：CRUD、状态流转（进行中→已完成→取消）自动联动库存锁定/扣减/释放；批量改状态；状态变更日志。
- 金额：收入/支出/净额/预计收入卡片，年份+月份（累计至该月）切换，点击卡片下钻到对应订单列表，红涨绿跌。
- 增强：仪表盘（今日新增、待处理、低库存预警、临近交期）、系统内通知提醒、基础权限（管理员/只读）、操作日志、一键全量 JSON/Excel 备份。

## 五、BOM 库存联动说明
- 订单引用「产品」时，除锁定该成品库存外，还会按 BOM **递归锁定/扣减其组成零部件**（符合"成品库存仅作展示、实际控制为零部件"）。
- 订单引用「零部件」时，直接锁定/扣减该零部件库存。
- 状态变更：进行中 → 锁定（lockedStock += qty）；已完成 → 扣减（stock -= qty，lockedStock -= qty）；取消/删除 → 释放。

## 六、Excel 导入模板
在任一列表页点「模板」即可下载该模块的导入模板（.xlsx），按列填写后用「导入 Excel」上传，系统自动校验并新增/更新（以编号为 key），错误行会提示并跳过。
